# Texas Comptroller Scraper

This repository contains a simple example script for fetching business entity information from the Texas Comptroller website.

## Usage

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the script:
   ```bash
   python tx_comptroller_scraper.py
   ```

Update `tx_comptroller_scraper.py` with the list of business names you want to search.
